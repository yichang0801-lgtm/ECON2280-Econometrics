# 版式来源

本笔记沿用既有 BMO 笔记的 `report` 模板：12pt、A4、单面、四边 2cm，保留章节与定理环境的层次。只添加中文、高亮、图表和 PDF 导航功能，没有重新设计笔记版式。

原 BMO 源码完整副本保留在本地，校验值见 `sources/manifest.json`。其内容不属于本次 OLS 笔记，因此不纳入公开仓库。实际使用的完整导言区已包含在根目录 `main.tex`，无需该原模板文件即可编译。

Windows 上使用原来的宋体、黑体与楷体；其他环境自动使用 TeX 发行版内置的 Fandol 中文字体。跨系统字体不同可能改变分页，但不改变正文与数学内容。
